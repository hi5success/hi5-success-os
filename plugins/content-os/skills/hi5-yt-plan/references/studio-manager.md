# Content Manager: the Monthly Studio Session

One session a month, worked week by week. The Content Manager plans and then hands off. It never writes captions and never schedules anything.

## Before the session
Read Studio Settings, the Studio SOP, each channel's Style Guide and Edit Log, the Content Profile, and the Content Calendar (what is already planned). Say in one line what you found.

## 1. The month's goal and what is coming up
Ask short questions, with A, B, C options where they fit:
- "What is the goal this month?" A) More leads or clients B) More awareness C) Promote a specific offer or event D) Something else.
- "What is coming up that we should make content about?" Industry-agnostic. For a real estate member the examples are new listings, property tours, open houses, and market updates. For other businesses, launches, events, seasonal offers, and client wins.

## 2. Research
Find what people search and what is trending, using the tools available this session: YouTube SEO (the research method in /hi5-yt-research, if YouTube is used), AEO (the questions people ask AI answer engines about the topic), and social trends for the picked platforms. Use vidIQ if it is connected. Use only data from a tool or the member. Never invent a search volume or a trend, and label anything you could not check.

## 3. Propose topics
Show a short table: topic, hook or angle, media type, platforms, and why it fits now. The member approves in the conversation. There is no approval click later. Keep the member's own ideas from the Content Planner (Status Idea) in the mix.

## 4. Balance the month
Mix media types and goals, respect the member's record schedule and capacity, and spread the pieces across the weeks. Set the publish dates first, with times in the member's time zone, and set each Edit Due Date from the Studio SOP (default 48 hours before the publish date). Clip dates come from the Clip Publish Date formula in the Content Planner. Only set the long-form's publish date. Never calculate clip dates in the skill.

### Recording days
Do not assign one record date per video. After the plan is set:
1. Ask: "Do you have a day you batch record?" A) Yes, which day B) No, I'll pick per video. If Studio Settings already has a batch_record_day, offer it as the default.
2. Show the list of videos to record and let the member group them (for example "1, 2 and 3 tomorrow, 4 to 6 next Tuesday").
3. Set each row's Record Date from the answer.
4. Recommend once, plainly: "Record at least 48 hours before Edit Due, so the editor has time to cut the video, clips, and posts before your review. Everything waits for your approval."
5. If a record date leaves less than 48 hours before Edit Due, flag it and offer A) move the publish date, B) record earlier, C) keep it as a rush. Do not choose for them.
6. If they have a batch day, save it in Studio Settings (batch_record_day) and default to it next month.

## 5. Write scripts and production notes (into the row's page)
- **Long-form and one-off shorts or reels:** type and style, the hook, a word-for-word script or talking points (ask which the member wants), recording tips, and edit notes (on-screen text, b-roll, music, pacing, from the Style Guide).
- **Static posts and carousels:** the topic, what the post covers (slide by slide for a carousel), the assets needed, and the post time. If a photo or screenshot is needed from the member, write it in Needs from member.
- **Clips:** no notes. The Editor finds them.
Write in the member's voice. Never invent facts, numbers, or results. For real estate content, run the Fair Housing check: no steering, and never describe who lives somewhere. Listing content uses only the listing facts the member gives.

Before the member sees any script or notes, run the pre-review check from the pipeline reference (no invented commitments, no income or results claims, no em dashes, Fair Housing on real estate content), and log "check passed" on each row.

## 6. Create the rows, folders, and starting statuses
For each approved piece:
- A row in the Content Planner with Deliverable Type, Platforms (Distribution), Record Date, Publish Date and time, and the Asset Folder URL. Status is Planned.
- A folder in the member's file location (../hi5-studio/references/folders.md).
- The notes in the page sections from the pipeline reference, with an empty Handoff checklist and Log.
For each long-form, create the clip rows: the count from Studio Settings (clips_per_long_form), adjustable per video. Each clip row has Deliverable Type Clip, Clip Number, the Parent long-form relation (and Related To with the parent title), the parent's platforms, and Status Planned. Leave the clip's publish date to the formula, then read the dates it shows and say them in one line so the member can change them.
Only create rows, folders, and roles for the channels the member picked. No YouTube means no YouTube-only rows or notes.

## 7. Hand off
Tell the member what to record and when, and that after recording they drop the files in the piece's Raw folder and set Ready to Edit. Add a Log line to every row. Nothing is scheduled.

## Never
Never write captions. Never change a status past Planned. Never schedule or post.
