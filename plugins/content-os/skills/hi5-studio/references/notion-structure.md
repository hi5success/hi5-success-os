# What Lives in the Member's Notion

The core rule: skills hold the craft, the member's Notion holds everything about the member. Plugin updates replace skill files, so nothing member-specific is ever written into a skill.

## Hi5 Studio page
A page under the workspace root called "Hi5 Studio" holds the Studio pages below. Save these IDs in the Master Profile Page IDs: `studio_page_id`, `studio_settings_page_id`, `studio_sop_page_id`, `cover_template_page_id`. The Content Calendar is the existing Content Planner (`content_planner_db_id`), so never create a second one.

## Studio Settings (one page, a bullet per field)
- platforms_in_use: Instagram, Facebook, TikTok, LinkedIn, YouTube (optional), other
- who_does_the_work: me, VA, team, or done-for-you
- done_for_you_lead: yes or no, with the date (a flag for Hi5 Biz Solutions, nobody is contacted by this skill)
- clips_per_long_form: default 5
- working_hours: days, hours, and time zone for scheduled roles
- file_location: Google Drive app, Dropbox app, or a local folder (with the path)
- scheduler: Hi5 scheduler or GoHighLevel (default), or another named scheduler
- cover_image_option: A (a still from the video), B (a cutout on a textured solid background), or C (a new image made in ChatGPT)
- bridges_detected: CapCut, YouTube uploader, GHL social, with the date they were last seen working
- scheduled_tasks: which role tasks the member turned on
- channel pages: one Style Guide page and one Edit Log page per channel (names and IDs)

## Studio SOP (one page)
The default pipeline from the pipeline reference, written in plain language, edited to match the member's answer to "what's different in how you work?" Keep the statuses and the order. Record the differences as short bullets at the top under "How we work here". Anyone who joins (a VA or a team member) reads this page first.

## Content Calendar changes (append only)
Add to the Content Planner. Never rename or remove anything.
- Status options: Planned, Ready to Edit, In Progress, Reviewing, Revising, Finalizing, Optimizing (Scheduled and Published already exist).
- Deliverable Type options: Clip, Static Post, Carousel (Long Form, Short Form, and Blog already exist). Short Form is a one-off short.
- Distribution is the Platforms field (multi-select). Add options as used.
- New properties: Clip Number (number), Needs from member (text).
- Record Date, Publish Date (with a time), Related To (the parent long-form title), and Asset Folder URL (the folder link) already exist.
If a property cannot be added (the connector refuses), put it as the first line of each row's page ("Clip Number: 2", "Needs from member: ...") and say so once. If adding a select option errors, create a row that uses the new option and then trash it (the seed row workaround).

## Per channel
- **Style Guide** (one page per channel): hook habits, pacing, caption voice and length, hashtag rules, edit style (cuts, captions, music, b-roll), cover style, and things to never do. Start from what the Master Profile and Voice Profile already say, then add the member's answers.
- **Edit Log** (one page per channel): a dated list of every correction (see the learning edits reference).

## Cover Template page
Layout notes (size, text position, fonts, colors, how the face or image is placed, the logo), plus a link to the last cover made, so every cover matches. Update the link whenever a cover is finished.

## Only build for the channels picked
Create Style Guides, Edit Logs, rows, folders, and roles only for the platforms the member chose. No YouTube means no Producer rows and no YouTube notes.

## If a Studio already exists
Find "Hi5 Studio" under the workspace. If it exists, skip setup, read Studio Settings and the SOP, save the IDs in the Master Profile, ask the member which role they are (me, VA, editor, team), and connect. Never recreate pages that exist.
