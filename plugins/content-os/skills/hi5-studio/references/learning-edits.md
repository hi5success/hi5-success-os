# Learning Edits

Every session reads the channel's Style Guide and Edit Log first. Corrections are written down the moment they are made, so the next edit already applies them.

## On any revision
1. Fix the notes.
2. Ask once, with short options:
> "Should I remember this?
> A) This piece only
> B) This channel
> C) All channels"
3. Write a dated line to the Edit Log right away (for A it goes on the row's Log only, for B to that channel's Edit Log, for C to every channel's Edit Log). Format: "2026-10-26 | Instagram | Cut the first 3 seconds of every intro | from: [row title]".
4. The next edit applies every Edit Log line for its channel before it starts, and says in one line which ones it applied.

## Promoting to the Style Guide
When the same correction appears three or more times, suggest moving it into the Style Guide: "You have asked for this 3 times. Want me to make it a Style Guide rule? A) Yes B) Not yet". Only promote with the member's OK, and keep the Edit Log lines. Never change a Style Guide rule without the member's OK.

## Never
Never write a correction to a Style Guide automatically. Never apply a "this piece only" correction to other pieces. Never delete Edit Log lines.
