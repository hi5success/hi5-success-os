# Claude Projects for Hi5 Success OS

Used by /hi5-next once, after the foundation steps are done. Recommend a few Claude Projects, one per topic, so each conversation stays focused and nothing gets mixed together. Every Project reads the same Master Profile from Notion, so nothing needs to be entered again.

## Why
- Each Project is one topic, so you can find a conversation again and the work does not get jumbled.
- Your Master Profile lives in Notion, so every Project already knows your business, your voice, and your rules.
- You can ask /hi5-next in any Project and it will give you your best next step.

## Suggested Projects
Only suggest the Projects that match what the member will actually use. Skip the YouTube Project if they have no channel. Skip a Project whose skills are all `coming` in `path.md`. Say what to run in each one.

| Project name | Purpose (one line) | Skills to run there |
|---|---|---|
| Hi5: YouTube and Content | Plan, script, and repurpose your video content | /hi5-yt-research, /hi5-yt-plan, /hi5-yt-script, /hi5-repurpose |
| Hi5: Social Media | Write captions and posts for every platform | /hi5-social, /hi5-linkedin |
| Hi5: Website and SEO | Get found on Google and convert visitors | /hi5-seo, /hi5-website, /hi5-blog, and /hi5-site-audit when it ships |
| Hi5: Email and Nurture | Follow up with leads and stay top of mind | /hi5-email, /hi5-newsletter |
| Hi5: Business Plan | Plan, set goals, and review your numbers | /hi5-bizplan, /hi5-goals, and /hi5-bizreview |

## How to create a Project
Give the member these numbered steps for the first Project they want, one at a time, and wait for them to finish each step. Offer screenshot help every time, and never assume menu names, because they change.

> "Here is how to set up a Project. If your screen looks different from my steps, send me a screenshot and I'll tell you exactly what to click.
> 1. In Claude, look for Projects (usually in the sidebar) and choose to create a new project.
> 2. Name it, for example 'Hi5: Social Media', and add a one line description.
> 3. In the project's instructions, add one line: 'This project uses my Hi5 Success OS skills for [purpose]. If I'm not sure what to do, I run /hi5-next.'
> 4. Make sure the Notion connector is switched on for this project, the same way you did during setup.
> 5. Start a new chat inside the project and run the first skill."

For the YouTube Project only, also tell them to add their `YOUTUBE_API_KEY` line to that project's instructions if they have one, and that instructions may only apply to new chats in the project.

## Rules
- Offer this once. Never nag. After offering, write `projects_offered: <today's date>` in the Setup Status section of the Master Profile. That is the only thing /hi5-next ever writes.
- If the member says no or "later", respect it and say they can ask any time ("how do I set up Projects?").
- If the member asks for this again later, give the steps again without checking the flag.
- Keep the wording simple. Do not assume they have used Projects before.
