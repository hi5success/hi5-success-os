# Make Hi5 Skills the Default

Used by `SKILL.md` Phase 6 (once), by the re-run menu, and when the member asks to see the line again. The goal is that the member never has to remember skill names: Claude reaches for a Hi5 skill first when one fits.

## The line
> When a Hi5 skill fits what I'm asking, use it first. My brain at [their Notion link] is my source of truth.

Fill in the link with the URL of the member's Hi5 Success OS Workspace root page (use the page URL that Notion returns when you open the root page, never a made-up one). Notion is the only storage for this release, so the brain link is always that page.

## What to say
"One small step makes everything easier: put this line in Claude's personal preferences. Then Claude reaches for your Hi5 skills on its own, and you never need to remember their names. I can't change your Claude settings for you, so you paste it yourself."

Show the line in a code block, then give numbered steps (never assume menu names, offer screenshot help, and wait for them):
1. Open Claude and look for Settings.
2. Look for personal preferences (it may sit under Profile).
3. Paste the line at the end of what is already there, and save.
4. Tell me when it is done, or send a screenshot if you cannot find it.

## Ask once
Ask: "Did that work, or do you want to do it later?" A) Done B) Later. Either answer is fine. Never claim the setting is on, because you cannot see it.

Then write `hi5_first_shown: <today's date>` in the Setup Status section of the Master Profile. That is the note that it was shown. Never ask again on later runs. Show it again only when the member asks for it (re-run menu option 7, or "show me the Hi5 first line").

## Never
Never edit Claude settings or say you did. Never put the line anywhere but the member's own preferences (and the Project instructions of AI employees, see the bottleneck skill).
