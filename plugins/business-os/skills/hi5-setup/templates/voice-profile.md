# Voice Profile: Page Template

Create a child page of the Master Profile called **Voice Profile** (icon 🎙️). Save its ID as `voice_profile_page_id` in the Master Profile's Page IDs section. Every Hi5 skill that writes in the member's voice reads this page.

If the page already exists (for example created earlier by /hi5-yt-setup), update it instead of making a new one. Keep any fields already on it, and add the new ones.

## Page layout

### Fields
- vocabulary_style: casual and conversational, professional and polished, or in between
- sentence_rhythm: short and punchy, long and flowing, or a mix
- emoji_use: never, sometimes, or often
- preferred_length: short, medium, or long
- phrases_used: phrases the member says constantly
- phrases_never_used: words and phrases to avoid
- avoid_em_dashes: yes or no. The default is yes
- how_to_come_across: for example calm expert, friendly neighbor, straight shooter
- energy_level: calm and measured, high energy, or in between (asked by /hi5-yt-setup for video)
- cta_style: direct, soft, or conversational (asked by /hi5-yt-setup for video)

### Default writing rules
Write these two lines on the page, under the fields:
- Never use em dashes in anything written for this member, unless avoid_em_dashes above is no. Use a comma, a colon, or a new sentence instead.
- Never use anything on the phrases_never_used list.

### Voice summary
The approved voice summary bullets (under 150 words). Write "not provided" if the member skipped writing samples.

### Proof samples
The three approved sample pieces in the member's voice. Write "not provided" if skipped.

### Gaps to watch
The three gaps and how to correct them. Write "not provided" if skipped.

## Edge section on the Master Profile
Write these fields under a heading 2 called **Edge** on the Master Profile page (create it if missing):
- client_situations
- differentiator
- proof_point: write `[ADD PROOF]` if the member had none
- client_words
