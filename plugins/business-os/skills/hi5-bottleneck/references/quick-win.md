# Building the Quick Win

Used by `SKILL.md` Step 6. Build only what is safe, and only with the member's OK. Show every piece before you create it.

## What you can build on the Claude side
- **Claude Project instructions.** Write them as text for the member to paste, with steps. Use `templates/project-instructions.md`. Screens differ between apps and versions, so never claim exact menu names. Say "look for", and ask for a screenshot if their screen does not match. Never say you created a Project, because you cannot. Tell them where to paste it.
- **A skill.** Write a complete skill (a folder named in lowercase words joined by hyphens, with a SKILL.md that has plain frontmatter, a name that matches the folder, and a description with no colons). Offer it through Claude's save skill card, and give a backup file with install steps (follow `../hi5-voice-creator/references/install-steps.md`). Include the Hi5 rules that apply to what it does (drafts first, one approved send at a time, consent gates, compliance, no em dashes, the member's voice for anything written to others).
- **A scheduled task.** Show the schedule, the exact prompt, and what it reads and writes. Create it only with the member's OK and only with a scheduling feature that is available in this session (say which one). Never claim to have scheduled something you did not. A scheduled task is read only or draft only, and never sends, publishes, spends, or changes records.
- **Notion databases and pages.** Reuse an existing database before creating one. Propose the fields and wait for the member's OK. If a Notion data source update errors when you add select options, create a row that uses the new option and then trash it (the seed row workaround), and say what you did.

## After building
Say what was built, where it is, how to test it, and what to watch for. Ask the member to note how long the task takes for two weeks, so the estimate can be checked on the next run.

## Never
Never send, publish, spend money, or change a record in the member's CRM or any platform from this skill. Never build a bulk or automatic sender. Never store secrets, passwords, or full account numbers in a Project, a skill, or Notion.
