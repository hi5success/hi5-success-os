# Installing the Backup Skill File

Used by `SKILL.md` Step 7. Give the member these steps with the file. Screens differ between apps and versions, so never claim exact menu names. Say "look for", and ask for a screenshot if their screen does not match.

## What you are giving them
A file named after the voice, for example `jacobs-voice` (a zip of the folder, or the `SKILL.md` file inside it). It is a complete skill. It works on its own, and it reads the latest guide from the Voice Library in Notion when Notion is connected.

## Steps
1. Download the file to your computer. Keep it somewhere you can find it.
2. In Claude, open Customize and look for Skills. Choose the option to add or upload a skill.
3. Pick the file. If your screen asks for a zip, upload the zip. If it asks for a folder, unzip first and pick the folder named for the voice.
4. Turn the skill on, if it asks.
5. Test it: type "write as [name]" or "in [name]'s voice" and ask for a short email. It should sound like the person.
6. If your screen does not match these steps, send a screenshot of the Skills area and I'll adjust the steps for it.

## If a save skill card appeared in the chat
Choose Save on the card. That installs the skill without a file. Keep the backup file anyway.

## Updating later
When the voice is updated, you get a new file with a higher version number. Replace the installed skill with the new file (remove the old copy first if your screen asks you to). The Voice Library entry is always the latest, so the skill reads it each time even before you reinstall.
