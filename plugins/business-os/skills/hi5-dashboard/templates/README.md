# Reference Dashboard Templates

This folder is for reference dashboards that the skill can use as starting points after discovery. Jacob's own dashboards will be added here later.

## How to add one
Add one file per template, named for who it is for (for example `real-estate-team-lead.md`). Each file lists:
- **Who it is for** and the industry.
- **Pages** in order, with the purpose of each.
- **Widgets** on each page, with the data source and the actions.
- **Notion trackers** it uses, with their fields.
- **Connectors** it needs, and what to do if one is missing.
- **Notes** on what worked and what the member dropped.

## How the skill uses them
After discovery, the skill may offer a matching template as a starting point and shows what it would change. A template is a suggestion, never forced, and every widget still has to pass "If you saw this, what would you do?" Never include a person's private data in a template: use placeholders.
