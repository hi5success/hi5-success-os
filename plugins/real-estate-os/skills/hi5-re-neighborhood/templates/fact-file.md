# Neighborhood Fact File: Page Template

Used by `/hi5-re-neighborhood`. The page is a child of the Master Profile called **Neighborhood – [Name]** (with an en dash, icon 🏘️), one per area, listed in the `neighborhoods` Page IDs entry as `Name = page id`. It is the same page `/hi5-setup` Stage 5 builds, with a source and a date on every fact. Never create a second page for an area. Add to the existing page.

The page describes the place, the homes, and the amenities. It never describes the people who live there, and it never rates schools or safety.

---

## Page layout

**First line of the page:**
> Facts marked "Needs verification" came from the agent and should be checked against an official source before they are published.

### Inputs
- area_name: {{area name}}
- last_updated: {{today's date}}
- refresh_by: {{a date the member chose}}

### Sections (write them in this order, with these exact names)
1. **Snapshot**: 5 bullets, each from a fact below.
2. **Homes and Prices**: price range, home styles, lot sizes, HOA details.
3. **Getting Around**: main routes, access, typical drive times as the agent gave them.
4. **Things to Do**: parks, trails, dining, shopping, events.
5. **Insider Notes**: best streets or sections for specific features, what surprises newcomers, seasonal quirks. Say readers should verify anything about drainage, flooding, or other risks with the official source.
6. **What Buyers, Renters, and Investors Should Ask**: questions to ask before buying, renting, or investing here.
7. **What Sellers and Landlords Should Know**: what moves fast, what inspections often flag, how to prepare. Add short notes for any other client type the member works with (commercial, land, new construction, 55+ communities, luxury, relocation), using only what the member told you.
8. **Content Angles**: 10 post or video ideas for this area.

### The fact table
Under each of sections 2, 3, and 4 (and anywhere a number appears), keep a table with these columns:

| Fact | Value | Source | Date | Status |
|---|---|---|---|---|

- **Source:** where the fact came from, in the member's words (for example "my MLS export", "the county appraisal district page I pasted", "my own sales"). Never fill in a source the member did not give.
- **Date:** the date of the data, or the date the member gave it.
- **Status:** one of "From the agent", "From a document the member pasted", or "Needs verification". Anything with no source stays "Needs verification".

## Rules for building and changing the page
- Use only what the agent told you or pasted. Do not add facts about the area that they did not give you.
- Remove any line that describes residents, school quality, or safety as fact. Replace it with a feature-based line about the place, or drop it. No steering language ("perfect for families", "safe neighborhood", "up and coming"). Follow the Compliance Guardrails page.
- Never state a price trend, appreciation, days on market, a tax rate, or a commute time without a source and a date. Never predict the market.
- Keep the old "[VERIFY + DATE]" marks readable. When you convert one to the table, keep its value and mark it "Needs verification" with the date on the mark.
- Show every change as a plan (Before and After) and wait for the member's OK before editing the page.
