# Directory and Citation Check

Used by `SKILL.md` (choice C). The goal is the same business name, address, and phone everywhere people look for the member. Inconsistent details confuse customers and search engines.

## Step 1: The details to match
Read `nap_name`, `nap_address`, and `nap_phone` and the website. If any are missing, ask once:
> "Exactly how do you want your business name, address, and phone number to appear everywhere? If you work from home or serve an area without a storefront, tell me and we'll hide the address."
Real estate members often use a personal name, a team name, and a brokerage name in different places. Ask which version to use, and note that the brokerage name must match how it is licensed. Save `nap_name`, `nap_address` (or "service area business, address hidden"), and `nap_phone`.

## Step 2: The directories to check
Use the list in the industry file. Check Google first, because it is the source other sites compare against.

## Step 3: Check each one
For each directory:
1. Use web search for the business name and city on that site, and read the public page that comes up. Read one page at a time.
2. Record: found or not found, the name, address, phone, and website shown, and the category.
3. Mark it **matches**, **differs** (say exactly what), **missing**, or **couldn't read**.
4. If a site blocks reading, never try to get around it. Give the member a two minute manual check: "Open [site], search your name and city, and tell me or send a screenshot of the name, address, phone, and website you see."
Never claim you checked a site you could not read. Never ask for logins.

## Step 4: Output
- A table: one row per directory with the result and what to fix.
- Fix steps, in this order: Google, Apple Business Connect, Bing Places, then the others. For each, general steps to claim or edit the listing, with screenshot help. Do not assume menu names.
- Any duplicate listings found, and what to do about them.
- Languages: if they serve other languages, note which listings allow a second language.

## Step 5: The GHL Listings add-on
Only if `website_platform` is GoHighLevel, or `crm` is GoHighLevel or Hi5 Connect: mention that the GHL Listings add-on, which is included with Hi5 Connect, can help keep listings consistent. Present it as an option, not a requirement. Do not mention it to members on other platforms.

## Save
Marketing Hub row "Directory and Citation Check" with the date (see `SKILL.md`). Save the `nap_*` fields and `last_citation_check` (today). Never edit or create a listing yourself.
