# Build It: Handoff Steps

Used by `SKILL.md` (Step 11). After the funnel is written, offer: "Want step by step instructions to build this in your platform?" These are instructions only. Never connect to the member's account, never publish, never send, and never ask for a password.

**How to give steps.** Describe where to look in general terms, such as "open your site or funnel builder and create a new page". Never assume exact menu names, because they change. Give one step at a time, wait for the member to finish, and say: "If your screen looks different, send me a screenshot and I'll tell you exactly what to click." Read any screenshot they send and tell them the next click.

Read `website_platform` and `crm` from the profile to pick the right section.

## GoHighLevel and Hi5 Connect
1. **Funnel or site pages.** Create the steps in this order: the sign-up page, then the thank-you page. Add each page's title and description from the funnel's saved rows. Paste the copy section by section.
2. **The form.** Fields: first name and email. Add a phone field only if the member's texting consent is documented, and then add a checkbox with the member's consent wording next to it. Make the form submit to the thank-you page. Add the full disclosure line and any required notices in the footer of every page.
3. **Tags.** Create a tag for the funnel (for example the funnel name) and a tag for the client type or offer, so contacts can be found later. Apply the tag when the form is submitted.
4. **Pipeline stage.** Choose or create a pipeline and a first stage such as "New lead". Add the contact to it when the form is submitted. Add a later stage for "consultation booked".
5. **Follow-up workflow.** Create a workflow that starts when the form is submitted. Add steps in order: apply the tag, add the contact to the pipeline stage, send email 1, wait, send email 2, and so on, using the wait times in the saved email sequence. Add an exit when the contact books a call or replies. Check that each email carries the disclosure line and an unsubscribe link.
6. **Booking.** If the next step is a call or consultation, add a calendar link on the thank-you page and in the emails.
7. **Test it.** Submit the form with your own email. Check the thank-you page, the first email, the tag, and the pipeline stage. Check the pages on a phone.
8. **Ads (if used).** Create the campaign in the ad platform using the ad pack and its launch checklist. Use tracking parameters on the link so leads can be traced back to the ad.
If the member uses the GHL Listings or reputation tools, mention them only where they fit the funnel. Do not claim features beyond what the member has.

## Other platforms: a general checklist
1. **Pages.** Create the sign-up page and the thank-you page with the copy, titles, and descriptions from the saved rows.
2. **Form.** Name and email, plus a phone number only with documented consent and a consent checkbox. Send people to the thank-you page after they submit.
3. **Email tool.** Create the follow-up sequence with the waiting times in the saved plan, tag or segment contacts from this funnel, and stop the sequence if someone books or replies.
4. **Footer.** Add the full disclosure line and any required notices on every page and email, and an unsubscribe link on every email.
5. **Booking.** Add a booking link or contact instruction to the thank-you page.
6. **Tracking.** Use tracking parameters on every link so results can be traced.
7. **Test.** Run through the whole path with a test contact, on a phone as well.
8. **Ads (if used).** Build the campaign from the ad pack and its launch checklist, and have the member check the platform's current policy first.
If the member's tools are unclear, ask once which page builder and email tool they use, and tailor the steps.
